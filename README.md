# Michi Frontend

Frontend da aplicação **Michi**, um sistema pessoal para organização de rotina, metas, estudos e finanças.

## Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- ESLint
- Prettier

## Desenvolvimento

Instale as dependências:

```bash
npm install
````

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

A aplicação ficará disponível em:

```text
http://localhost:5173
```
